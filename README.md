# Khushaank Courses · AI Masterclass

A responsive landing page covering prompting, ChatGPT, AI assistants, Ollama, and privacy.

Website: https://khushaank.github.io/ai-masterclass/

## Editing

Edit `index.html` for content, `style.css` for styling, and `app.js` for the prompt examples and dialogs. `hero.png` is the founder portrait; `syllabus.txt` is the downloadable course outline.

This is a static website with no build step or dependencies. GitHub Pages serves the repository root from `main`. Push changes to `main` to update the website.
